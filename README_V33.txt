StockTool V33 — Primary Valuation Engine

V33 replaces the six-method weighted-average decision valuation.

Key changes:
- Selects 2–4 valuation methods based on industry, lifecycle, growth, SBC, and data quality.
- Uses the same selected methods for fair value today and future exit value.
- Requires method corroboration and automatically downweights outliers.
- Mature/utility/dividend businesses cannot receive 30%+ base returns from rerating.
- Growth and semiconductor businesses use forward cash-flow/earnings methods and no longer let weak owner-earnings estimates dominate.
- Legacy six-method consensus remains in results for audit only.
- New result field: valuation.primaryValuation.
